## Overview

NATSUKAGE (夏影, "Summer Shadow") is a retro Japanese open-world exploration experience that captures the atmosphere of late Showa-era Japan. Explore a lovingly crafted 10x expanded world featuring multiple distinct towns, scenic countryside, and iconic landmarks including Mount Fuji.

## Features

- **Three Distinct Towns**: Explore Natsukage Old Town, Saitama-Shintoshin Vice Metropolis, and Fujiyoshida Lake Town
- **Iconic Landmarks**: Visit Mount Fuji, Chureito Pagoda, scenic lakes, shrines, and traditional Japanese architecture
- **Drivable Vehicles**: Summon and drive cars, bikes, military tanks, helicopters, and speedboats
- **Custom Railway System**: Build your own railway tracks and ride the commuter train
- **Living World**: Dynamic NPCs, ambient pedestrians, traffic, and day/night cycle
- **Atmospheric Audio**: 80s/90s Saitama Blues radio with ambient town sounds
- **Seasonal Variety**: Experience different seasons with appropriate visuals
- **Interactive Elements**: Collectibles, quests, destructible buildings, and interior spaces
- **Retro Aesthetic**: Authentic late 70s-90s Japanese town vibes with pixel-perfect nostalgia

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/natsukage.git
cd natsukage
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

### Building for Production

```bash
npm run build
```

This will create optimized builds in the `dist/` directory. The build process also generates a standalone HTML bundle.

### Preview Production Build

```bash
npm run preview
```

## Controls

| Key | Action |
|---|---|
| `WASD` / Arrow Keys | Move |
| `Mouse` | Look around |
| `Space` | Jump / Interact |
| `E` | Interact with objects/NPCs |
| `Tab` / `M` | Open map/menu |
| `R` | Respawn vehicle |
| `V` | Switch vehicle/camera views |
| `F` | Enter/exit vehicle |

*Check the in-game Controls menu for the complete keybindings.*
