## 🌸 Overview

NATSUKAGE (夏影, *Summer Shadow*) is a retro Japanese open-world exploration experience inspired by the atmosphere of late Showa-era Japan. Explore a sprawling world of traditional neighborhoods, scenic countryside, neon-lit city districts, and iconic Japanese landmarks.

From peaceful lakeside towns to towering skyscrapers, discover a world filled with vehicles, railways, interactive locations, and nostalgic atmosphere.

**Explore the world:** [natsukage.vercel.app](https://natsukage.vercel.app/)

## 🎮 Features

- **Three Distinct Towns** — Explore Natsukage Old Town, Saitama-Shintoshin Vice Metropolis, and Fujiyoshida Lake Town.
- **Expansive Open World** — Discover interconnected environments, mountain roads, countryside, and an expanded metropolitan district.
- **Iconic Japanese Landmarks** — Visit Mount Fuji, Chureito Pagoda, scenic lakes, shrines, and traditional architecture.
- **Vibrant City Districts** — Experience skyscrapers, neon-lit streets, casinos, and lively plazas inspired by retro open-world games.
- **Drivable Vehicles** — Take control of cars, bikes, military tanks, helicopters, and speedboats.
- **Custom Railway System** — Build railway tracks and ride commuter trains through the world.
- **Living World** — Encounter NPCs, pedestrians, traffic, and a dynamic day-and-night cycle.
- **Atmospheric Audio** — Enjoy nostalgic 1980s–1990s-inspired radio and ambient environmental sounds.
- **Interactive Exploration** — Discover collectibles, quests, enterable interiors, and interactive objects.
- **Seasonal Variety** — Experience changing environments with seasonal visual elements.
- **Retro Japanese Aesthetic** — Immerse yourself in the nostalgic atmosphere of 1970s–1990s Japan.

## 🕹️ Controls

| Key | Action |
|---|---|
| `W` `A` `S` `D` / Arrow Keys | Move |
| Mouse | Look around |
| `Space` | Jump / Interact |
| `E` | Interact with objects and NPCs |
| `Tab` / `M` | Open map or menu |
| `R` | Respawn vehicle |
| `V` | Switch vehicle or camera views |
| `F` | Enter or exit vehicle |

*Check the in-game Controls menu for the complete keybindings.*

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 16 or higher)
- npm or yarn

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   cd YOUR_REPOSITORY
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL displayed in your terminal, usually `http://localhost:5173`.

### Build for Production

```bash
npm run build
```

The optimized production build is generated in the `dist/` directory.

### Preview the Production Build

```bash
npm run preview
```

> **Note:** The commands above assume the repository contains the game's source code and its `package.json`. Adjust them if this repository contains only the landing page or project description.
